# Cathode BTA

A Better Than Adventure mod that adds monitors and speakers. Put monitors together to make bigger screens, then play retro console games, browse the web or watch videos on them.

Friends can play together on the same screen in multiplayer games, up to four players on the N64.

## Requirements

- Babric

## Building

```
./gradlew build
```

The jar ends up in `build/libs`.
